# Visual Novel Editor (가칭 StorySim Studio)

## 1차 구현 — 브라우저 프로토타입 (2026-10-25)

[**에디터 소스: index.html**](index.html)

현재는 빌드 도구가 필요 없는 단일 HTML 프로토타입입니다.

### 실행
```bash
git clone https://github.com/JamesJung/visual_novel_editor.git
cd visual_novel_editor
python3 -m http.server 8080
```
브라우저에서 `http://localhost:8080`으로 접속합니다. `index.html`을 직접 열어도 기본 기능을 사용할 수 있지만 로컬 서버 실행을 권장합니다.

### AI 마스터 생성 실행

Node.js 22 이상에서 실행합니다.

```bash
cp .env.example .env
# .env의 OPENAI_API_KEY에 본인의 API 키 설정
npm run dev
```

`http://localhost:8080` → 캐릭터 스튜디오 → 설명·화풍 입력 → 마스터 이미지 생성 → 검토 후 채택. API 키는 브라우저나 프로젝트 JSON에 저장되지 않습니다. ChatGPT 구독과 API 사용 요금은 별도이며, 생성마다 API 비용이 발생합니다. 모델은 서버의 OPENAI_IMAGE_MODEL로 변경할 수 있습니다.

기본값은 로컬 1인용 서버입니다. 인증 없이 외부에 공개하지 마세요. 정적 HTTP 서버에서는 업로드/편집만 가능하고 AI 생성은 Node 서버가 필요합니다.

생성 결과는 검토 대기 상태이며, 채택 전 기존 마스터를 유지합니다. 채택 시 이전 마스터·표정 세트를 보존하고 기존 씬은 이전 버전을 참조합니다. 새 씬은 새 마스터를 사용합니다. 수동 업로드 경로의 기존 덮어쓰기 제한은 남아 있습니다. 이미지 후보 다운로드 및 JSON 백업을 지원합니다. 로컬 저장 공간 초과 시 채택을 되돌립니다.

테스트: `npm test` · [생성 기능 검증 기록](docs/MASTER_GENERATION.md)

### 마스터 기반 표정 variation

캐릭터 스튜디오에서 마스터를 등록/채택한 뒤 **생성할 표정 → 선택한 표정 생성**을 누릅니다. 기본·웃음·걱정·분노·울음·놀람 6종을 각각 생성할 수 있습니다. 각 요청은 마스터 PNG 원본을 직접 참조합니다. 후보와 마스터를 비교하고 **검토 후 표정 승인**을 눌러 적용합니다. 후보 버리기/다운로드도 가능합니다.

현재 지원 마스터: PNG, 1024×1536 / 1536×1024 / 1024×1024. 마스터 버전 또는 후보 해상도가 다르면 승인되지 않습니다. 같은 해상도가 얼굴 일관성을 보장하지 않으므로 직접 검수해야 합니다. 표정마다 API 비용이 발생하며 자동 재시도·일괄 생성은 하지 않습니다. 의상/포즈 variation은 후속 범위입니다.

승인한 표정을 교체하면 이전 에셋과 기존 씬의 참조를 보존합니다. 새 씬은 최신 승인 표정을 사용합니다. [구현 및 검증 기록](docs/EXPRESSION_VARIATIONS.md). 실제 유료 API 왕복은 키 설정 후 확인해야 합니다.

### 지금 작동하는 기능
- 프로젝트 이름 변경, 샘플 프로젝트 초기화
- 캐릭터 등록 및 설정 수정, 마스터/표정 6종 이미지 업로드
- 원본 이미지 크기 확인, 마스터와 표정 이미지의 **해상도 동일 여부** 검사, 승인/승인 취소
- 마스터 이미지와 선택한 표정 이미지 나란히 미리보기
- 씬 목록, 캐릭터/표정, 대사, 배경색, 선택지, 다음 씬 편집
- 간단한 수치 효과(`현금 -100`, `제품 완성도 +20`)의 플레이 테스트
- `localStorage` 자동 저장 및 JSON 가져오기/내보내기

### 중요한 한계
- **얼굴 유사도 평가, 자동 정렬/정규화, 계정/서버 프로젝트 저장 및 SaaS 결제는 아직 구현되지 않았습니다.** AI 마스터 생성은 API 키 설정이 필요합니다.
- 승인 기능은 동일 해상도만 확인합니다. **같은 크기 = 같은 얼굴/같은 좌표**는 아닙니다.
- 업로드 이미지는 브라우저 로컬 저장소 용량 제한을 받습니다(파일당 4MB 제한).
- 마스터를 다시 업로드하면 해당 캐릭터의 표정 이미지는 초기화됩니다. 불변 버저닝은 후속 작업입니다.
- 실제 Chrome 브라우저에서 프로젝트·캐릭터·씬·플레이를 검증했습니다. [검증 기록](docs/BROWSER_QA.md)
- 회귀 테스트: `node --test tests/player.test.cjs` (Node.js 필요). 배포 검증은 별도입니다.
- public GitHub 저장소에 파일을 커밋한 것이며, GitHub Pages 배포는 별도 설정이 필요합니다.

### 리뷰 순서
1. 캐릭터 스튜디오에서 동일한 인물 이미지 6종 업로드
2. 크기가 다른 이미지를 넣고 경고/승인 제한 확인
3. 씬 편집기에서 표정/대사/선택지를 바꿔보기
4. 플레이 테스트에서 분기와 변수 값 확인
5. JSON 내보내기 후 다시 가져오기

AI 기반 **웹 비주얼 노블·선택형 시뮬레이션 게임 제작 SaaS**.

> 핵심 약속: 한 번 승인한 캐릭터의 정체성과 화면 비율을 유지하면서, 대화·표정·의상·장면을 반복 생산한다.

## 제품 방향
- 타깃: 개인 개발자, 인디 게임 팀, 웹소설/IP 제작자, 소규모 스튜디오.
- 제작: 캐릭터 스튜디오 → 에셋 검수 → 스토리/선택지 → 변수/규칙 → 플레이 테스트 → 웹 게임 배포.
- 재사용: 야구 육성, 스타트업 경영, 직장인 생존 등 서로 다른 프로젝트에 공통 엔진 사용.
- 편집은 웹 기반; 게임 실행은 웹 우선, 모바일 패키징은 추후 지원.
- AI는 **제작 시에 사용**하고, 게임 중에는 **승인된 에셋을 재사용**하는 방식을 기본으로 한다.

## 왜 별도 프로젝트인가?
기존 `JamesJung/second_ball`의 캐릭터 제작/합성 경험을 교훈으로 삼되 Flutter 게임 코드를 단순 복사하지 않는다. 기존 구현에는 머리·몸 합성, 앵커, fade, per-character 보정, 여러 렌더 경로가 있다. 오류 원인을 실측하지 않은 상태에서 기존 접근을 반복하지 않는다.
