# 제품 기획서 — Visual Novel Editor / StorySim Studio

상태: Draft v0.1 · 2026-10-25

## 1. 비전
'게임을 코딩하기 전에 이야기와 캐릭터를 안정적으로 제작하고, 선택형 시뮬레이션으로 출시하는 웹 스튜디오.'

**생산 도구로서 판매**한다. AI 일회성 이미지 생성 사이트가 아니라 인물·에셋·스토리·게임 규칙·배포의 전체 흐름을 연결한다.

## 2. 고객 및 해결할 문제
- 혼자 개발하는 인디 창작자: 일러스트 제작, 선택지 엔진, 에셋 관리 부담.
- 소규모 콘텐츠 팀: 작가/기획자/아티스트/개발자 협업 및 버전 관리.
- 웹소설/IP 보유자: 스토리를 인터랙티브 콘텐츠로 변환.

기존 고통: 프롬프트 반복으로 얼굴/머리/체형이 변하고, 별도 표정 atlas 크기와 캔버스가 달라 조립 시 찢어짐·확대·밀림이 발생한다. 화면 보정값이 캐릭터마다 증가하고 오류 원인이 불명확해진다.

## 3. 제품의 차별화 가설
1. **마스터 고정 + 에셋 승인 게이트:** 원본/정규화/조립 결과를 사용자에게 함께 노출.
2. **일관성 측정 가능:** 이미지 차이/랜드마크 차이/비균일 변형 여부를 표시하되 'AI 동일 인물 100% 보장' 금지.
3. **제작 후 게임까지:** 캐릭터를 프로젝트별 스토리와 연결, 웹 플레이어로 테스트·배포.
4. **장르별 규칙 확장:** 야구 성장, 스타트업 경영, 회사 생활 시뮬레이션 등.

## 4. 사용자 여정
1. 프로젝트 생성, 해상도/화풍/게임 목표 설정.
2. 등장인물 이름·특징·관계 등록.
3. 이미지 생성/업로드 → 마스터 확정.
4. 마스터 기반 같은 포즈 표정 세트 생성 → 자동 검사 → 미리보기 → 사용자 승인.
5. 씬 에디터에서 배경·캐릭터·표정·대사·선택지 배치.
6. 상태 변수(자금, 관계, 성장, 평판 등)와 선택 효과·조건 구성.
7. 브라우저 테스트 플레이, 분기/실패 검사.
8. 웹 패키지 빌드/배포 또는 export.

## 5. 예시 게임
### 통산타율 .125
야구 훈련/성장, 감독·동료 관계, 습격 배후, 선택에 따른 엔딩. 첫 기술 검증용 레퍼런스이며 원본 저장소 직접 수정은 별도 승인 필요.

### 스타트업 시뮬레이션
창업 자금, 런웨이, 제품 완성도, 팀 사기, 투자자 신뢰 등 변수를 가진 선택형 경영 게임. 공동창업자와 채용 후보의 호감도/신뢰, 피벗/투자/인수/파산 분기.

## 6. 사업화 가설(검증 전)
- 무료 체험 + 유료 플랜: 프로젝트/보관 용량/협업 기능 차등.
- 생성 이미지 크레딧 별도 계량: 이미지 요청 수, 모델 비용, 재시도 및 실패 과금 정책 명시.
- 출판/export/상업적 이용 권리는 제공자 라이선스 및 생성 모델 약관 검토 후 정의.
- 우선 직접 제작하는 파일럿 1종과 외부 사용자 3~5명 인터뷰로 유료 수요 검증.

## 7. 비목표(초기)
- 동영상 캐릭터 애니메이션, Live2D 급 실시간 리깅.
- 모든 AI 포즈의 완벽한 일치 보장.
- 복잡한 멀티플레이, 스토어 전용 앱 빌드.
- 실시간 플레이 도중 AI 그림을 무제한 생성하는 기능.

## 8. 제품 성공의 정의
제작자가 이미지 오류를 설명하고 직접 고칠 수 있으며, **1인물 6표정의 전환에서 조립 비율/위치가 예측 가능하고**, 짧은 분기형 데모를 에디터에서 만들어 웹으로 실행할 수 있어야 한다.
