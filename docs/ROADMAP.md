# 개발 로드맵 v0.1

시간 예측보다 **완료 가능한 검증 게이트** 기준으로 진행한다.

## Phase 0 — 기존 오류의 재현 (선행 필수)
- [ ] `second_ball` 코드/문서 기반 테스트 시나리오 준비.
- [ ] 문제가 발생한 실제 이미지와 사용 메타데이터 수집.
- [ ] raw / normalized / rendered 3단계 비교 리포트.
- [ ] 크기·좌표·비균일 스케일·경계 오류 분류.
**종료 조건**: 최소 1가지 오류를 재현하고 수정 방향의 검증 증거를 확보.

## Phase 1 — Character Studio PoC
- [ ] 프로젝트/캐릭터/마스터 업로드·승인 및 버전 보존.
- [ ] 동일 pose 표정 6종 등록.
- [ ] canvas/anchor/alpha/비율 자동 검사.
- [ ] normalized 미리보기, 사용자 수동 정렬·승인.
- [ ] 웹 Canvas 표정 전환 검증.
**종료 조건**: 승인된 표정 세트에서 화면 전환·리사이즈 시 의도치 않은 늘어짐/이동 없음.

## Phase 2 — 콘텐츠 저작 MVP
- [ ] 배경/캐릭터/표정/대사/선택지 씬 저작.
- [ ] 변수·조건·효과 및 간단한 분기.
- [ ] 게임 플레이어·세이브/로드.
- [ ] 2캐릭터/2배경/10씬 데모.
**종료 조건**: 에디터 데이터로 코딩 없이 브라우저에서 분기형 게임 동작.

## Phase 3 — AI 제작 파이프라인
- [ ] provider adapter 1종.
- [ ] 생성 잡/큐/재시도/취소/비용/프롬프트 기록.
- [ ] 참조 이미지와 마스크 편집 워크플로.
- [ ] 품질 경고·부분 교체·승인 UI.
**종료 조건**: 생성 → 검수 → 장면 배치의 이력이 추적되고 실패 시 복구 가능.

## Phase 4 — 제품화
- [ ] 인증·프로젝트 격리·역할별 권한.
- [ ] web publish/export, 빌드 버전.
- [ ] 사용량 대시보드/한도, 결제 검토.
- [ ] 데이터/라이선스/삭제 정책 및 보안 리뷰.
- [ ] 파일럿 사용자 피드백.
**종료 조건**: 외부 창작자가 안전하게 프로젝트를 만들고 데모를 게시 가능.

## Phase 5 — 확장
- [ ] 의상·포즈별 rig, 파츠 조합(검증 후).
- [ ] 스타트업 게임용 자금·팀·제품·투자 시뮬레이션 플러그인.
- [ ] 시나리오 그래프 분석/일괄 에셋 제작.
- [ ] 협업·템플릿 시장·모바일 빌드.
